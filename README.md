
# Summer 2026 Research Project

## Main Objectives

- [ ] Implement the Fast Whitehead Minimization Algorithm in Python 3 for Free Groups up to rank 26
- [ ] Update a publicly available Python 2 module written by Cashen and Manning that, among other things, computes relative JSJ decompositions of free groups relative to elements.
- [ ] Investigate the conjecture on the number of elements of minimal length in an automorphic orbit.
